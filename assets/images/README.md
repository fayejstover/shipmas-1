# Images

|----------|-------------|------------------|
| `stairs.png` | Diagonal staircase | 900×700px, transparent |

| `cat2.png` | Second cat | 80×80px, transparent |
| `tree.png` | Holiday tree | 180×280px, transparent |

## Optional

| Filename | Description |
|----------|-------------|
| `preview.png` | Preview image for README |

## Notes

- All images should have transparent backgrounds
- Presents should have full, vibrant color (they desaturate during unwrap)
- Cats should face right (walking direction)
- Stairs should slope from top-left to bottom-right
